# Contributing

Thanks for taking a look.

**Wrong numbers come first.** If a figure on the site is wrong, open an issue
or email hello@skylarkcreations.com. Link the page and a source showing the
correct figure.

**Code changes.** Open an issue first for anything bigger than a small fix, so
we can agree on the approach before you spend time on it. Then:

1. Fork the repository and make your change on a branch.
2. Run `npm run typecheck` and `npm test` from the repository root. Both must pass.
3. Open a pull request saying what changed and why.

**Facts need sources.** Any change that adds or alters a figure about a person
must cite a primary or authoritative source. Unsourced figures will not be
merged. Never add private addresses, family details or anything that affects
someone's personal safety.

**Never commit secrets.** Keys and passwords belong in your local `.env`,
which is git-ignored.
