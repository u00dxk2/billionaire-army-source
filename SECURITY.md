# Security

If you find a security problem in Billionaire Army, please email
**hello@skylarkcreations.com** instead of opening a public issue.

Please include:

- what you found and where (a URL, file or endpoint),
- the steps to reproduce it,
- what someone could do with it.

We will reply as soon as we can and keep you posted until it is fixed. Please
give us a reasonable chance to fix it before you tell anyone else.

Please do not access, change or delete other people's data, and do not run
tests that degrade the live site for everyone else.
